# Universal Sheet

Excel-like frontend spreadsheet SDK. Framework-agnostic core with Vue 3 and React bindings. Publishable to npm.

## Packages

| Package                     | Description                                               |
| --------------------------- | --------------------------------------------------------- |
| `@universal-sheet/core`     | Pure TypeScript data structures and algorithms (zero DOM) |
| `@universal-sheet/engine`   | Canvas-based rendering engine                             |
| `@universal-sheet/formula`  | Formula parsing and computation engine                    |
| `@universal-sheet/ui-vue`   | Vue 3 component bindings                                  |
| `@universal-sheet/ui-react` | React component bindings                                  |
| `@universal-sheet/shared`   | Internal utility functions                                |

## Quick Start

```bash
# Install dependencies
pnpm install

# Start playground
pnpm dev

# Run all tests
pnpm test

# Build all packages
pnpm build

# Lint all packages
pnpm lint
```
